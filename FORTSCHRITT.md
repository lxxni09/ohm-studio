# Fortschritt – Ohm Studio by Nodaris

## Für dich (Inhaber) (Stand: 12.11.2026 – alle 9 Schritte von Ohm Studio 3.0 sind gebaut)

**Neuester Setup-Assistent zum Herunterladen:**
👉 **https://github.com/lxxni09/ohm-studio/releases/latest**

Dort die Datei **`OhmStudio-Setup-3.0.0-offline.exe`** nehmen (ca. 110 MB, alles drin). Der automatische Build legt dort nach jeder Änderung die neueste Fassung ab.

**So installierst du es auf einem Windows-PC (5 Schritte):**
1. Solange das Projekt **privat** ist: auf dem PC im Browser bei **GitHub anmelden** (sonst geht der Link nicht). Ist es öffentlich, geht der Link für alle.
2. Den Link oben öffnen und `OhmStudio-Setup-3.0.0-offline.exe` anklicken → wird heruntergeladen.
3. Die Datei doppelklicken. Windows zeigt vielleicht **„Der Computer wurde durch Windows geschützt“** – das liegt daran, dass das Programm noch nicht digital signiert ist. Auf **„Weitere Informationen“** und dann **„Trotzdem ausführen“** klicken.
4. Im Setup-Assistenten: **Weiter → Häkchen bei „Ich akzeptiere“ → „Nur für mich“ → Weiter … → Installieren**.
5. Am Ende ist **„Ohm Studio jetzt starten“** angehakt → **Fertigstellen**. Ohm Studio öffnet sich in seinem eigenen Fenster.

**Was du ausprobieren kannst (ca. 10 Minuten):**
1. Beim ersten Start läuft eine **60-Sekunden-Tour** – am Ende blinkt dein erstes Projekt.
2. Blauer Knopf **„Neues Projekt aus Idee“** → z. B. „Eine Lampe, die angeht, wenn es dunkel wird“ → durchklicken bis „Bestellen“ (Kosten bei 1/5/100 Stück, Gehäuse, Platine).
3. Reiter **Start → Beispiele → Fußgängerampel**, ▶ drücken, gelben Taster klicken. Von Null anfangen: **Start → „Leeres Projekt“** (oder im Ideen-Assistenten „Leer starten“).
4. Knopf neben „Neues Projekt aus Idee“: **Community-Galerie** – Beispiele öffnen und **remixen**.
5. Reiter **Datei → Importieren**: eine KiCad- oder Altium-Datei öffnen (z. B. von einem Freund).
6. **Echter ESP32:** Reiter **Einstellungen → Emulatoren** → „ESP32-Werkzeuge installieren“ (einmalig ca. 1,5 GB, 10–30 Minuten). Dann **Schlüssel-Türwächter** öffnen, unten „Arduino C++ · echter ESP32 (Emulator)“ wählen, ▶.
7. Reiter **Einstellungen → Transparenz**: zeigt, dass alle Einnahmequellen aus sind.

**Neu (12.11.2026, auf deinen Wunsch):** Oben ist jetzt eine **Menüleiste mit Reitern** wie in CAD-Programmen (Datei · Start · Simulation · Platine & Fertigung · Analyse & KI · Team · **Einstellungen** · Hilfe), sachlicherer Stil (grau/blau, eckiger). Der Fehler, dass man nicht in die Einstellungen kam (das „…“-Menü wurde abgeschnitten), ist damit weg. **Clip-Funktion entfernt.** **Tastenkürzel** gibt es als Knopf oben in der Leiste (Reiter Einstellungen oder Hilfe → „Tastenkürzel“), außerdem zeigt jeder Knopf sein Kürzel, wenn du mit der Maus drauf bleibst (z. B. „Speichern (Strg+S)“); neu: **F11** für Vollbild. Neuer Knopf **„Leeres Projekt“** (Strg+N).

**Was noch nicht funktioniert (ehrlich):**
- **Galerie, Teilen-Link, Marktplatz** brauchen einen Server im Internet – bis dahin zeigt die Galerie nur die Beispiele.
- **Automatische Updates** und der kleine Web-Installer gehen erst, wenn die Downloads **öffentlich** sind.
- Die **Windows-Warnung** beim ersten Start bleibt, bis ein Code-Signatur-Zertifikat gekauft ist.
- „Neues Projekt aus Idee“ baut ohne **Claude-API-Schlüssel** nur aus Vorlagen.
- Echter ESP32 auf Windows: auf einem echten Windows-Rechner (GitHub) **bestanden** – Werkzeuge laden, klassischer ESP32 und der Türwächter-Abnahmetest mit dem ESP32-C3 (5× Blinken in 1,01 s, Alarm nach 2,27 s). Aber: Das **erste** Übersetzen dauert dort gut 2 Minuten, und der **klassische ESP32** startet im Emulator unter Windows oft erst nach mehreren automatischen Neustarts (in einem Lauf 8 Fehlversuche am Stück) – der ESP32-C3 ist die zuverlässigere Wahl.

**Was du selbst erledigen musst (mit deinen Eltern):**
- Entscheiden, ob die Downloads öffentlich werden (Checkliste, Abschnitt „Downloads veröffentlichen“). **Das Repository ist geprüft und kann gefahrlos öffentlich werden** – keine Schlüssel, Passwörter oder Lizenzcodes drin.
- Für Galerie und Teilen-Link: Server + Domain + Impressum + Moderation (Checkliste, „Community-Galerie einschalten“).
- Alles mit Geld (Pläne, Partner-Links, Bausätze, Marktplatz): **nur mit Zustimmung deiner Eltern** – Checkliste „Einnahmen einschalten“.
- Alles Weitere (Marke, Domain, Rechtstexte): `rechtliches/BETREIBER-CHECKLISTE.md`.
